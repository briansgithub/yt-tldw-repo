YT-TLDW Options

Play curated YouTube moments (Ask/Gemini for Facts/Funny; most-replayed scrub-bar graph for Popular) and always skip SponsorBlock sponsor / selfpromo / interaction segments.

API uses the current panel’s exact server-issued free-text command once, without replaying a stored continuation. Auto remains DOM-first while this path gains live coverage. Genre Popular uses only YouTube’s most-replayed graph (HEATSEEKER or player SVG)—Ask/Method settings do not apply. Genre, Intensity, and Method apply when you click Apply (re-runs the current video).

On/Off and Debug log apply instantly; they do not wait for Apply.

Toolbar

Left-click the extension icon for On/Off, Debug log, and staged Genre/Intensity (Apply). Right-click the icon for On/Off, Debug log, Genre, and Intensity (menus apply immediately). The in-player button still toggles On/Off.
