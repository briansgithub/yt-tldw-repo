YT-TLDW Options

Play curated YouTube moments (Ask/Gemini for Facts/Funny; most-replayed scrub-bar graph for Popular) and always skip SponsorBlock sponsor / selfpromo / interaction segments.

Applies instantly to the popup, this page, and the queue page.

API uses the current panel’s exact server-issued free-text command once, without replaying a stored continuation. Auto remains DOM-first while this path gains live coverage. Genre Popular times come only from YouTube’s most-replayed graph (HEATSEEKER or player SVG). Intensity picks which peaks qualify and blends section length: Aggressive = max-curvature edges, Weak = nearest local minima, Mild = halfway. After those windows exist, one Ask/Gemini pass titles them; Ask cannot re-time the sections. Apply always re-runs extraction on the current video and jumps to the first section when ready.

On/Off and Debug log apply instantly; they do not wait for Apply.

Toolbar

Left-click the extension icon for On/Off, Debug log, and staged Genre/Intensity (Apply). Right-click the icon for On/Off, Debug log, Genre, and Intensity (menus apply immediately). On the watch page, the in-player controls are previous segment, auto-jump toggle, and next segment (extension On/Off stays in the popup/toolbar).
